# Krish Desai — Academic Website

Personal academic website for [Krish Desai](https://www.desai.ml), a machine learning researcher at Lawrence Berkeley National Laboratory working on unfolding, inference, and practical statistics for particle physics. Built with [Jekyll](https://jekyllrb.com/) and hosted on GitHub Pages at **[desai.ml](https://www.desai.ml)**.

## Local Development

### Prerequisites

- Ruby (managed via `rbenv` or system Ruby)
- [Bundler](https://bundler.io/)
- Node.js & npm
- [uv](https://docs.astral.sh/uv/) (Python package manager, Python 3.13+)

### Setup

```bash
bundle install   # install Ruby gems
npm install      # install Node.js tools
uv sync          # install Python packages
```

### Serve

```bash
bundle exec jekyll serve --livereload
```

The site is available at `http://127.0.0.1:4000`.

### Build

```bash
# Production build
bundle exec jekyll build

# Minify JavaScript (_main.js → main.min.js)
npm run build
```

## Content Collections

Each collection lives in a `_<name>/` directory. Files use date-prefixed slugs (`YYYY-MM-DD-descriptive-slug.md`) with YAML frontmatter.

### Publications (`_publications/`)

```yaml
---
layout: publication
title: "Paper Title"
collection: publications
category: manuscripts   # manuscripts | conferences | preprints | theses
permalink: /publications/2024-01-01-slug
date: 2024-01-01
venue: "Journal or Conference Name"
paperurl: "https://..."
citation: "Author et al. (2024). ..."
authors: "<strong>Krish Desai</strong>, Co-Author"
# Optional link fields:
doi: "10.xxxx/..."
arxiv: "2401.xxxxx"
scix: "..."
inspirehep: "..."
researchgate: "..."
code: "https://github.com/..."
---
```

Wrap your own name in `<strong>` tags to bold it in author lists.

### Talks (`_talks/`)

```yaml
---
layout: talk
title: "Talk Title"
collection: talks
type: "Talk"             # Talk | Poster | Seminar
permalink: /talks/2024-01-01-slug
venue: "Conference Name"
date: 2024-01-01
location: "City, Country"
link: "https://..."
---
```

## Python Scripts

### `talkmap.py`

Geocodes talk locations via the [Nominatim](https://nominatim.org/) API and generates interactive [Leaflet](https://leafletjs.com/) maps in the `talkmap/` directory.

```bash
uv run talkmap.py
```

### `update_cv.py`

Reads YAML frontmatter from `_publications/`, `_talks/`, `_experience/`, and `_teaching/` and writes structured data to `_data/cv.json`.

```bash
uv run update_cv.py
```

## CI/CD

Three GitHub Actions workflows automate deployment and data updates:

| Workflow | Trigger | Action |
|---|---|---|
| `pages.yml` | Push to `master` | Builds Jekyll site and deploys to GitHub Pages |
| `update_cv.yml` | Changes to collections or `update_cv.py` | Runs `update_cv.py` and commits updated `_data/cv.json` |
| `scrape_talks.yml` | Changes to `_talks/` or `talkmap.py` | Runs `talkmap.py` and commits updated map files |
